Coding My Portfolio

March-April 2020

Problem

Typical portfolios follow a stock build from a typical web builder. I did not want that, and I sought to improve my coding abilities.

Context

I need to understand the building blocks behind my designs. Practicing coding will help my designs become more friendly to developers.

Objective

To finish Coding the website in order to share my experience with employers.

Planning

I used Figma to iterate several ideas for my portfolio. My first iteration came about with free reign, not considering the coding task in hand. I created wireframes that consisted of a complex layout. Including pictures on top of pictures.

Coding

Using code pen to start coding, I discovered it was extremely difficult to align all of the items properly. Back to the drawing board. I got rid of the shapes and sought a simplier layout. I also kept in mind the need for responsive design. I created mobile wireframes for the portfolio. I intentionally created them in the easiest manner possible for the media queries I would have to code.

Problems

The best way to describe my first attempt at coding the website is “hacky”. Items were willed into place using “relative” and “absolute” in CSS. Although this worked, it did not have responsive capabilitites.

The second time around was better. I got rid of the clutter, and became more consistent in how I aligned items. I used flexbox and proper margins to keep everything in the right alignment. I still had three problems. What is the proper way to use margins? For example, do I give the margin to the top piece of content, the bottom, or split on both? Needless to say, without planning ahead, I have instances of each. The second problem is with responsive design. Instead of hard pixels, I used vh or vw for pictures. At certain screen sizes it looks good, but it gets bad quickly as soon as you decrease the size. I also do not want to implement several media queries to resize the content at each problem point. The third problem, comes from the lack of standardized labeling for CSS. For example, I would give the research title a class of “researchtitle”, and style it in CSS. However, coming to the Ideation title, I realized that the same “researchtitle” class would work in styling the rest of the titles. Luckily, this weird inconsistency won’t confuse others since it isn’t a shared project among developers.

Lastly, I only know HTML and CSS (front end). In order to get a working website I will have to either learn a lot more, or ask for help.

Solutions

Each iteration came with solutions from my brother. Showing me how to better implement each design. furthermore, upon calculated the time it took to get two iterations done, I decided to outsource the help even more. Using VS Code, and github, my brother was able to help me with making the website functional and more professional.

We did not want to recreate a backend for the site, so we utilized a service for the form fields to gather information. We also used amazon web services to host the site.

Next Steps

Creating my own website has given me a more holistic perspective of the development process. I want to be more empathetic towards developers with my designs. I decided to get help with this site so I could start applying to jobs sooner, but that does not hault my yearning for more knowledge in web development. My dream is to continue learning and become a full stack developer in order to implement better UX designs.
