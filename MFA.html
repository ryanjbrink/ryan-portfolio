Mission French Africa

December 2019

Problem

Mission French Africa’s website is outdated, and needs better usability. The goal is to update and increase functionality for visitors.

Context

Mission French Africa is a non profit organization that needed an update. The website had an old and unorganized look.

Objective

I was responsible for reorganizing and updating the UI of Mission French Africa’s website. The whole process took 5 weeks.

Freestyle UI

Home

A lot is happening on the home page. Keeping design simple is always a great bet. I sought to decrease the clutter and highlight the important parts to the page.
I wanted to highlight the most important elements in the home page.
I have a call to action to donate at the top instead of the bottom.
The most engaging piece of content is the video from the old website.
This explains very well what Mission French Africa is, and a user doesn’t have to go a page deep in order to discover who they are.

About

There is no need to have two pages for the about section. A better layout can offer all the information without needing to toggle between both.
I used more engaging imagery.

Utilizing icons and a map to show the impacted areas in Africa.

All the about information is included in this one page providing an easier usability instead of toggling between three pages.

Ministries

There is no need to have three pages for the Ministries section. Again, a user will want to view all Ministries at once, and click into each for more information.
I have all three ministry areas on one page. Each section shares a sneak peek into each ministry. The user can choose to learn more about each section if interested.

Donate

The old website made my eyes bounce around, and I did not know where to focus my attention. The Donate page needs an obvious call to action with a variety of payment options and a clear process.
A more prominent call to action for a specific amount.

The user can select where to send the money.


The primary red button indicates how the user submits their donation.

Contact

The contact page is already well put together, but the new one follows some basic UI design principles. I also added the address to this page to complete the contact info.
I utilized Material Design for the form fills.

I decreased the size of the fill boxes to reflect the amount of text that will be put into each form field.
